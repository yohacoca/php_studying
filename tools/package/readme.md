## php 常用的库


### JWT
> #### 安装
> - composer require firebase/php-jwt
> #### 介绍
> - 一个简单的库，用于在 PHP 中编码和解码 JSON Web 令牌 （JWT），符合 RFC 7519

### PhpSpreadsheet
> #### 安装
> - composer require phpoffice/phpspreadsheet
> #### 介绍
> - 一个简单的库， 是一个用于处理 Excel 文件的 PHP 库，主要功能包括读取和写入电子表格。它支持多种格式，如 .xlsx 和 .xls，并提供丰富的功能

### Guzzle
> #### 安装
> - composer require guzzlehttp/guzzle
> #### 介绍
> - Guzzle 是一个功能强大的 PHP HTTP 客户端库，可以用来发送 HTTP 请求并处理响应。它具有简洁且灵活的 API，支持多种请求类型，并适用于各种场景，如API调用、网页抓取等
